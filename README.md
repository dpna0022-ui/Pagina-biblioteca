Este proyecto consiste en una página web de una biblioteca llamada "Biblioteca", creada con HTML y CSS. Su objetivo es ofrecer una interfaz simple donde los usuarios puedan acceder a las principales funciones de la biblioteca mediante un menú.
Al abrir la página, se muestra el título de la biblioteca y una imagen representativa. Debajo aparece un menú desplegable, desde el cual el usuario puede acceder a tres secciones: Registro, iniciar sesión y catálogo de libros

¿Cómo se usa?

Se abre la página principal en un navegador.
Se hace clic en el botón Menú.
Se selecciona la opción que desea utilizar:
Registro para registrarse.
Iniciar sesión para acceder con una cuenta.
Catálogo de libros para revisar los libros que están disponibles.
